# 💳 Credit Wise Loan System

A Machine Learning-based loan approval prediction system that helps evaluate loan applications by analyzing applicant financial and demographic information. The project applies data preprocessing, exploratory data analysis (EDA), feature engineering, and classification algorithms to predict whether a loan should be approved.

---

## 📌 Project Overview

Financial institutions receive thousands of loan applications every day. Manually evaluating each application can be time-consuming and prone to inconsistencies.

The Credit Wise Loan System uses Machine Learning techniques to analyze applicant data and predict loan approval status based on factors such as income, credit score, debt-to-income ratio, employment status, education level, and existing loans.

---

## 🎯 Objectives

- Analyze loan applicant data.
- Identify key factors influencing loan approval.
- Build predictive machine learning models.
- Compare model performance using evaluation metrics.
- Provide data-driven insights for loan decision-making.
